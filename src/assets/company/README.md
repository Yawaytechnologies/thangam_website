# Company photographs

The five supplied photographs are connected through `../company-photos.ts`. Their original filenames are preserved.

| File | Photo | Placement |
| --- | --- | --- |
| image4.png | Blue project signboard | Home project gallery |
| image3.png | Group holding brochures at an indoor event | About gallery |
| image5.png | Four people presenting a project brochure | About story and gallery |
| image2.png | Group visiting the outdoor project site | Home project gallery |
| image1.png | Indoor meeting with a speaker | About gallery |

Gallery cards preserve the entire photograph and link to the full image. The brochure presentation replaces the About story's stock photo. Update the imports and captions in `../company-photos.ts` when replacing or adding photographs.

Build with `npm run build` from the frontend folder to include these local images in the deployment output.
